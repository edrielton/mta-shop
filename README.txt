MTA STORE
O MTA STORE é uma plataforma web completa desenvolvida para o ecossistema do Multi Theft Auto (MTA:SA), com foco em oferecer uma experiência fluida, segura e automatizada para gerenciamento de produtos, itens ou serviços voltados a servidores e jogadores.
Principais Funcionalidades
 * Catálogo e Vitrine Interativa: Interface dinâmica para exibição de itens disponíveis para compra ou resgate.
 * Gerenciamento em Tempo Real: Controle automatizado de estoque e transações integrado ao banco de dados.
 * Autenticação de Usuários: Sistema seguro para login e gerenciamento de contas e carrinhos.
 * Infraestrutura em Nuvem: Deploy contínuo e alta disponibilidade para garantir que a loja fique acessível 24/7.
Tecnologias Utilizadas
 * Backend & Banco de Dados: Supabase (gerenciamento de dados e autenticação)
 * Hospedagem & Deploy: Railway (infraestrutura da aplicação)
 * Domínio: Registrado e gerenciado via Hostinger (mtabrasil.site)
Como Funciona
A arquitetura do MTA STORE foi desenhada para separar o processamento e garantir performance. A interface web consome os serviços em nuvem hospedados na Railway, enquanto o Supabase atua nos bastidores lidando com as requisições de banco de dados, regras de segurança e tabelas de usuários e produtos de forma instantânea.
