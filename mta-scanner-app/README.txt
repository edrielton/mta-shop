=============================================
 MTA STORE SCANNER v1.0
=============================================

COMO USAR:
  Clique duas vezes em: ABRIR-SCANNER.bat
  (não precisa instalar nada)

CONFIGURAÇÃO:
  1. URL do Site: https://seusite.railway.app
  2. Token: mesmo token do config.lua
  3. Pasta: pasta "resources" do seu servidor MTA
     Ex: C:\MTA\server\mods\deathmatch\resources

DICAS:
  - Amarelo = VIP detectado
  - Azul    = Veículo
  - Verde   = Moedas
  - Roxo    = Kit/Item
  - A coluna "Comandos" mostra os /comandos do mod
  - Após enviar, acesse Admin > Resources MTA no site
