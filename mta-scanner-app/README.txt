=============================================
 MTA STORE SCANNER v2.0
=============================================

COMO USAR:
  Clique duas vezes em: ABRIR-SCANNER.bat
  (nao precisa instalar nada)

CONFIGURACAO:
  1. URL do Site: https://mtastore.site
  2. Token: mesmo token do config.lua
  3. Pasta: pasta "resources" do seu servidor MTA
     Ex: C:\MTA\server\mods\deathmatch\resources

VERSÕES DISPONÍVEIS:
  - PowerShell (ABRIR-SCANNER.bat) — recomenda Windows
  - HTML (MTA-Store-Scanner.html) — abre no Chrome/Edge
  - Python (scanner.py) — precisa Python 3.7+ instalado

DICAS:
  - Amarelo = VIP detectado
  - Azul    = Veiculo
  - Verde   = Moedas
  - Roxo    = Kit/Item
  - A coluna "Comandos" mostra os /comandos do mod
  - Apos enviar, acesse Admin > Resources MTA no site

SOLUCAO DE PROBLEMAS:
  - Se der erro 401: token invalido, verifique config.lua
  - Se der erro de conexao: URL incorreta ou site offline
  - URL sempre com https:// no inicio (ex: https://mtastore.site)
